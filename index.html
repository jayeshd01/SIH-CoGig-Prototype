CoGig Platform Quick Launcher

Modern full-stack web applications run through local servers to provide secure database connections, live APIs, and background job telemetry.

🚀 How to launch in 1 Click:

  1. Double-click START_COGIG.bat in this folder (d:\CoGig).
  2. It starts the NestJS Backend (port 3000) & Vite Frontend (port 5173), waits until ready, and opens automatically.
  3. Or run npm start in PowerShell or Command Prompt.
Open CoGig App (http://localhost:5173) → Backend API Healthcheck
